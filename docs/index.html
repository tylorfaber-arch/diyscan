What it does

Everything the generic OBD-II standard gives you, in a dashboard that's readable at a glance.

!

Read & clear codes

Stored, pending and permanent codes with plain-English descriptions, severity and tips. Clearing asks first.

◔

Live gauges

RPM, speed, coolant, fuel trims, O2 sensors, timing, MAP and more, with history graphs. Pick only the sensors you want.

✓

Smog readiness

See which emissions monitors are complete before you go for an inspection.

❄

Freeze frame

Engine conditions at the moment a code was set: RPM, load, temps and trims.

●

CSV drive logs

Record any set of sensors to a spreadsheet-ready file for later analysis.

+

Imports for any make

Add manufacturer sensors with Torque-style PID lists (GM, Ford, Toyota and more), switch them per vehicle, or browse Chrysler's DRB-III database.

▶

Built-in demo vehicle

No adapter yet? Tap “Try the simulator” to explore every screen with a demo vehicle that has a few common faults.

Install in a minute

It's not on the Play Store, so Android will ask you to allow it once.

  1. Download the APK on your Android phone or tabletTap the Download button above. Your browser may warn that the file type can be harmful. Choose “Download anyway”.
  2. Open the downloaded fileIf you see “Install unknown apps”, allow it for your browser, then go back and tap Install.
  3. Pair your adapterPlug the adapter into the port under the dash and turn the key on. In Android Bluetooth settings, pair it. The PIN is usually 1234 or 0000.
  4. ConnectOpen DIY Scan, allow Bluetooth, and tap your adapter. Older vehicles can take 5–10 seconds to answer the first time.

Compatibility

Any car or light truck sold in the US from 1996 on, EU petrol from 2001, EU diesel from 2004.

Adapter tip: Many $10 “ELM327” clones only work on CAN. For pre-2008 vehicles, use a known-good adapter such as OBDLink MX+, OBDLink LX or Vgate iCar Pro.

DIY Scan is a hobby project. Generic OBD-II only, so ABS, airbag and transmission modules aren't supported yet. Don't use it while driving. · GitHub
